【电脑端使用】PC / Mac / Linux
------------------------------------------------------
Windows 用户：
  双击 start.bat → 自动启动服务器 → 浏览器自动打开

Mac / Linux 用户：
  终端执行 bash start.sh → 自动启动服务器 → 浏览器自动打开

如果未安装 Python：
  1. 访问 https://www.python.org/downloads/ 下载安装
  2. 安装时勾选 "Add Python to PATH"
  3. 重新双击 start.bat


【手机端查看】iPhone / Android
------------------------------------------------------
方法一：GitHub Pages（推荐，免费永久）
  1. 注册 GitHub 账号：https://github.com
  2. 新建仓库，上传本文件夹全部内容
  3. Settings → Pages → Source 选 main 分支 → Save
  4. 等待1分钟，获得网址：https://你的用户名.github.io/仓库名/
  5. 手机浏览器打开该网址即可

方法二：电脑和手机在同一 WiFi 下
  1. 电脑先启动服务器（双击 start.bat）
  2. 查看电脑 IP 地址：
     Windows: 打开 cmd 输入 ipconfig，找 IPv4 地址
     Mac: 系统偏好设置 → 网络
  3. 手机浏览器访问：http://电脑IP:8080


【进阶】自定义内容
------------------------------------------------------
编辑 index.html（记事本打开），找到 SITES 数组：
  · name: 点位名称
  · left/top: 地图上的标记位置（百分比）
  · desc: 文字介绍
  · photos: 照片路径

替换照片：将图片放入 photos 文件夹，更新对应点位
的 photos 数组即可。

【常见问题】
------------------------------------------------------
Q: 双击 index.html 照片不显示？
A: Chrome/Edge 安全策略阻止了本地文件加载图片。
   请使用 start.bat 启动服务器后访问。

Q: 手机怎么用？
A: 推荐用 GitHub Pages（免费），或电脑开服务器后
   手机连同一 WiFi 访问电脑 IP。

Q: AI 问答功能提示"未配置密钥"？
A: 在 config.js 中填写智谱或月之暗面的免费 API Key。
   不填写也不影响地图交互和照片浏览。

Q: 照片太大加载慢？
A: 建议单张照片控制在 200KB 以内，
   可用 tinypng.com 在线压缩。

Q: 如何修改地图上的热点位置？
A: 用记事本打开 index.html，找到 SITES 数组，
   修改每个点位的 left 和 top 百分比数值。
