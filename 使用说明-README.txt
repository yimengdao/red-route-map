【电脑端使用】PC / Mac / Linux
------------------------------------------------------
Windows 用户：
  双击 start.bat → 自动启动服务器 → 浏览器自动打开

Mac / Linux 用户：
  终端执行 bash start.sh → 自动启动服务器 → 浏览器自动打开

如果未安装 Python：
  1. 访问 https://www.python.org/downloads/ 下载安装
  2. 安装时勾选 "Add Python to PATH"
  3. 重新双击 start.bat


【手机端查看】iPhone / Android
------------------------------------------------------
方法一：在线版（推荐）
  已部署网址：https://yimengdao.github.io/red-route-map/

方法二：电脑和手机在同一 WiFi 下
  1. 电脑先启动服务器（双击 start.bat）
  2. 查看电脑 IP 地址：
     Windows: cmd 输入 ipconfig，找 IPv4 地址
     Mac: 系统偏好设置 → 网络
  3. 手机浏览器访问：http://电脑IP:8080


【文件结构】

  index.html          主页面

【网页照片说明】
------------------------------------------------------
· 网页默认读取 photos_web/ 内的优化图片，手机端加载更快
· 全部原始大图保留在 照片素材-原始大图/ 对应点位文件夹中
· 原始大图不影响网页运行，可单独分发或留作他用


【常见问题】
------------------------------------------------------
Q: 双击 index.html 照片不显示？
A: Chrome/Edge 安全策略会阻止本地文件加载图片，
   请使用 start.bat 启动服务器后再访问。

Q: 照片太大加载慢？
A: 本版本已内置优化图片（photos_web），无需手动压缩。

Q: AI 问答功能提示"未配置密钥"？
A: 在 config.js 中填写智谱或月之暗面的 API Key 即可，
   不填写也不影响地图交互和照片浏览。

Q: 如何修改地图上的热点位置？
A: 用记事本打开 index.html，找到 SITES 数组，
   修改每个点位的 left 和 top 百分比数值。

Q: 手机上怎么切换点位？
A: 底部导航可直接切换；打开点位后抽屉内
   有"上一个 / 下一个"按钮，无需退回总览。
